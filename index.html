Edge Quantum 65 est un laboratoire de R&D basé à Lannemezan (Hautes-Pyrénées). Nous développons, mesurons et publions nos travaux — c'est un travail d'artisan autant que d'ingénieur.

Philosophie

Quatre principes guident chaque décision technique. Ils ne se négocient pas.

Souveraineté

Aucune fonction de coût, aucun seuil de sécurité, aucune mise à jour ne vient d'un serveur distant. Tout est gravé en flash, non modifiable.

Déterminisme

Une entrée donnée produit toujours la même sortie. Pas d'aléatoire caché, pas de génération stochastique. Le système est certifiable.

Frugalité

Inférence en microsecondes sur CPU à 240 MHz. Pas de GPU, pas de mémoire vive au-delà du mégaoctet. Le silicium coûte, l'énergie aussi.

Air-Gap natif

Aucune connexion réseau obligatoire. La puce peut être noyée dans la résine, inaccessible physiquement. L'intelligence reste opérationnelle hors-ligne pendant 20 ans.

Champion vs Challenger

Boucle évolutive locale. Deux jeux de poids s'affrontent sur la même machine. Le meilleur est promu selon une fonction de coût L gravée en flash, jamais par Internet.

auto-optimisation

Fonction de coût L

L = α·Énergie − β·Rendement + γ·Pénalité. Coefficients α, β, γ non modifiables après compilation. C'est la métrique physique qui guide l'apprentissage.

physique, pas statistique

Boucle Champion / Challenger

Notre algorithme central. Pas d'IA générative, pas de réseau pré-entraîné à télécharger : la machine apprend d'elle-même, en local, à partir d'une métrique physique. 

    # Boucle CvC — pseudocode
    L = α·E − β·R + γ·P     # fonction de cout (fixee en flash)

    champion   = poids_initiaux
    challenger = mutation_gaussienne(champion)

    boucle:
        mesure_capteurs() → E, R, T
        p_champ   = champion.propose_commande(E, R, T)
        p_chal    = challenger.propose_commande(E, R, T)
        appliquer(p_champ)     # commande reelle
        challenger.calcule_en_shadow()  # prediction, pas d'action

        si L_challenger + ε < L_champion  sur k fenetres:
            promouvoir(challenger → champion)
        sinon:
            challenger = mutation_gaussienne(champion)
            # l'ancien champion reste en memoire pour retrogradation

Le système n'a pas besoin de label — la fonction de coût L est le label. Il apprend en observant la machine réelle, pas un dataset pré-étiqueté. C'est ce qui distingue notre approche des solutions cloud : aucune annotation manuelle, aucun transfert de données, aucun risque de violation de propriété industrielle.

Sécurité & Souveraineté

Cinq couches de protection indépendantes. Aucune ne suffit seule, toutes ensemble rendent l'extraction économiquement non rentable.

1. Potting physique

Résine époxy bi-composant (MG Chemicals 832B). Conductivité thermique 0,5 W/m·K. Noyage intégral des composants sensibles. Ouverture forcée = destruction.

2. Tamper detection

Tamper switch mécanique sous le potting. Tamper mesh (3 couches de pistes en serpentin sur le PCB). Toute coupure déclenche l'effacement instantané des clés en RAM.

3. Secure Boot + Flash Encryption

Le microcontrôleur refuse tout firmware non signé. La flash est chiffrée AES-256-XTS. STM32 RDP niveau 2 = JTAG définitivement bloqué, irréversible.

4. Signature par Device ID

Chaque firmware est lié à l'UID unique du microcontrôleur cible. Le binaire refuse de booter sur une autre puce. Clé privée stockée uniquement dans un HSM distant.

5. Pas de code source livré

Seuls les binaires chiffrés et signés sont fournis. Jamais le code source Rust, jamais les poids NNUE finaux, jamais l'architecture de la fonction de coût L.
